# NerveSystem Media

Local-first media automation tools.

## Clipper Agent

The first module is a zero-paid-credit clipping pipeline for video you own or are authorized to process:

`source video -> local transcription -> local highlight ranking -> vertical reframe -> captions -> review manifest -> MP4 export`

Core principles:
- no paid AI APIs required
- local models first
- modular providers
- human review before publishing
- no DRM or Content-ID bypass features
- preserve third-party license notices when compatible code is reused

Development is happening on the `build/clipper-v1` branch.
