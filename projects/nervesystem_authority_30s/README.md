# First Photoreal Integration Production

Project: **Who Authorized It?**

Purpose: force the entire NerveStudio stack to prove it can create a real commercial rather than a motion-graphics slideshow.

Success requires:
1. consistent human operator,
2. believable control-room environment,
3. industrial machine shot,
4. software/finance action shot,
5. voiceover,
6. sound design,
7. VFX authority layer,
8. final edit,
9. QC report,
10. finished 30-second master.

The project is intentionally shot-based. Each shot can be produced by the strongest available tool and replaced later without rebuilding the whole commercial.

## Preferred tool assignment

- Control room / operator: digital-human or AI-video adapter, with Blender set fallback
- Industrial robot: Blender or AI-video adapter
- Software/financial inserts: native compositing / motion graphics
- Authority layer / receipts: Blender compositor or FFmpeg/motion graphics
- Voice: local voice adapter
- Final assembly: FFmpeg
- QC: studio QC manifest

No stage is considered complete based only on text generation. A rendered artifact is required.
