# NOVO WORLD AI — Two-Host Podcast Pilot

This project proves the exact high-end use case the studio is being built for:

- two consistent synthetic hosts,
- two stable local voice profiles,
- local lip sync,
- realistic studio environment,
- speaker-aware multi-camera editing,
- long-form master,
- automatic clipping afterward.

## Required local assets

The first full render requires:
- an approved/authorized reference or idle video for Maya,
- an approved/authorized reference or idle video for Axel,
- a Voicebox profile for each host,
- MuseTalk-Mac local service,
- FFmpeg,
- optional LTX/Blender wide-shot/set footage.

The character identities are synthetic. Do not use a real person's likeness without authorization.
