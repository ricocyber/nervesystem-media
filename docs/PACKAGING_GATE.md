# Packaging Gate

NerveStudio does not begin expensive production merely because an idea sounds interesting.

A project must contain:
- a complete idea scorecard,
- at least 10 title variants,
- at least 3 thumbnail concepts,
- a selected package,
- a production script and shot list.

The Virality Director then applies the same internal score used elsewhere:
- Core / Casual / New audience fit
- stakes
- curiosity gap
- hook promise + proof
- title/thumbnail potential
- novelty
- timeliness
- production feasibility
- funnel fit
- shareability

The first NerveSystem commercial currently scores above the internal 85-point PRODUCE threshold.

This is an editorial gate, not a claim that a platform algorithm will make the video viral.
