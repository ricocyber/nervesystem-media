# Content Growth Operating System

## Objective

Turn existing research into a measurable content machine rather than a pile of isolated tips.

## The operating loop

1. **Research**
   - audience problems
   - competitor top/worst performers
   - comments and arguments
   - current news / trends
   - our own historical performance

2. **Idea generation**
   - generate 100 candidate concepts
   - narrow, tactical ideas before broad brand philosophy
   - identify the content funnel job: discovery, trust, or conversion

3. **Virality gate**
   - Core / Casual / New audience fit
   - stakes
   - curiosity
   - promise + proof hook
   - shareability
   - production feasibility

4. **Packaging round**
   - 10 title variants
   - at least 3 thumbnail concepts
   - title and thumbnail must complement rather than duplicate each other

5. **Production**
   - only produce ideas that survive the gate
   - scripts use simple spoken language
   - deliver value before brand introduction or CTA

6. **Distribution**
   - long-form YouTube creates depth/trust
   - Shorts/Reels/TikTok acquire attention
   - one successful long-form asset can become multiple short-form derivatives

7. **Measurement**
   - preserve Source -> Clip -> Edit Version -> Publication lineage
   - track packaging changes separately from the video edit
   - compare cohorts by channel, language, format, topic, duration band, and publication week
   - separate public counters from owner-authorized analytics

8. **Learning**
   - identify which hook types, topics, pacing, packaging, and lengths outperform comparable cohorts
   - recycle winning concepts with new angles
   - feed winners back into the next idea-generation round

## Revenue priority

Do not optimize only for view count.

Track:
- qualified leads / inquiries when relevant
- subscriber conversion
- sponsorship / affiliate / product revenue
- editing + compute + licensing cost
- contribution margin by content asset

The system should answer:
1. Which moments deserve editing?
2. Which edits deserve publishing?
3. Which patterns outperform comparable content?
4. Did the content create enough economic value to justify production?

## Starting channel strategy

The first channel should be one channel we control and can legally measure end-to-end. Multi-channel expansion comes after the lineage, analytics, and feedback loop are reliable.
